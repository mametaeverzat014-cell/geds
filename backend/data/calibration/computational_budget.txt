# GEDS Calibration Computational Budget Estimates

## Phase 1 — CMA-ES MAP (gradient-free)

- Dimension: 81 free parameters
- CMA-ES default population: ~17 (= 4 + floor(3 * ln(81)))
- Iterations to convergence: ~300–800 (empirical for 80-dim problems)
- Total evaluations: 17 × 600 ≈ 10,200 simulator calls × 5 restarts ≈ 51,000
- Per-eval time (estimate): 0.1–2.0 sec (depending on GEDS simulation cost)
- Total Phase 1 time:
  - If GEDS = 0.1 s/eval:  ≈ 85 min (single CPU)
  - If GEDS = 1.0 s/eval:  ≈ 14 hours (single CPU)
  - If GEDS = 1.0 s/eval with 16-core parallelism: ≈ 53 min

## Phase 2 — NUTS posterior sampling

- Warmup: 1000 draws × 4 chains = 4000 simulator evals
- Sampling: 2000 draws × 4 chains = 8000 simulator evals
- Total: ≈ 12,000 evaluations
- Total Phase 2 time:
  - If GEDS = 0.1 s/eval:  ≈ 20 min
  - If GEDS = 1.0 s/eval:  ≈ 3.3 hours

Note: NUTS requires differentiable log-posterior; if GEDS is non-differentiable, use GVI/SVI surrogate instead (see Phase 2b).

## Phase 2b — GVI/SVI (surrogate, JAX-GPU)

- Stochastic gradient steps: ≈ 5000–10,000
- GPU (RTX 3090+): ≈ 2–10 min for 1000-node model
- Scales approximately linearly with number of firms/nodes in simulator

## Phase 3 — LOEO-CV

- 21 folds × (Phase 1 reduced: 3 restarts, ~3000 evals each) ≈ 189,000 evals
- CPU-parallel (21 jobs): comparable to Phase 1 wall-clock time
- GPU-parallel: ≈ 2–5 hours

## Phase 4 — Bootstrap uncertainty

- 1000 resamples × forward pass only (no re-calibration): ≈ 21,000 evals
- At 1 s/eval: ≈ 6 hours serial; trivially parallelizable

## Recommended total compute budget

- Minimum (Phase 1 + LOEO-CV): ≈ 20 CPU-hours or ≈ 2 GPU-hours
- Full analysis (all phases): ≈ 80 CPU-hours or ≈ 8 GPU-hours
- Cloud cost estimate (4× A10G GPU): ≈ USD 5–20 for full run
